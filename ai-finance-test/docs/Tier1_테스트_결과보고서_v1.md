## 4. 실패 원인 — 3가지 (1개는 채점 코드 결함, **수정 완료**)

### 원인 ① 종목명 — **채점 코드 regex 버그** (오답 5건) → ✅ **2026-08-24 수정 완료**

`score_extraction.py:92`에 펀드코드 접미사를 떼고 비교하는 로직이 **이미 들어가 있다.**
그런데 패턴이 좁아 문서 내 펀드코드 3종 중 1종만 잡는다.

```python
FUND_CODE_SUFFIX = re.compile(r"\(?[A-Z]\d{4,}\)?$")   # 영문 1자 + 숫자 4자리 이상
```

| 코드 | 문서 내 등장 | 형태 | 현재 regex |
|---|---|---|---|
| `B5268` (샘플 A) | 4회 | 영문 1 + 숫자 4 | ✅ 매칭 |
| `EH735` (샘플 C) | 4회 | 영문 **2** + 숫자 **3** | ❌ **미매칭** |
| `DY904` | 7회 | 영문 **2** + 숫자 **3** | ❌ **미매칭** |

그래서 C 샘플의 `...(주식혼합)(EH735)`가 오답 처리됐다.
원문 검증 결과 접미사 없는 형태 60회 / `(EH735)` 형태 1회로 **ground_truth가 맞고**,
이 로직의 원래 의도(표기 변형이지 AI 오류가 아님)도 맞다. **regex만 틀렸다.**

**적용한 수정** — 괄호를 제거하기 *전에* `(코드)` 형태만 뗀다:

```python
FUND_CODE_SUFFIX = re.compile(r"\([A-Z]{1,3}\d{3,}\)\s*$")

def norm_fund_name(s: str) -> str:
    return norm_name(FUND_CODE_SUFFIX.sub("", s or ""))
```

> ⚠️ 괄호를 먼저 지우고 `[A-Z]{1,3}\d{3,}$`로 넓히는 방식은 **쓰면 안 된다.**
> `삼성KODEX200` → `삼성KO`, `미래에셋TIGERTDF2045` → `미래에셋TIGER`처럼 정상 종목명이 잘린다(실측 확인).

**결과: 종목명 22/27 → 27/27. API 재호출 없이 기존 `raw/*.json` 재채점만으로 회복.**
부수적으로 "확신 있는 오답"이 5건 → **0건**이 됐다(7절).

### 원인 ② 레버리지배율 (오답 10건, 전부 null) — 프롬프트 문제

B·C는 비레버리지 상품이라 투자설명서에 **"1배"라는 표현이 아예 등장하지 않는다.**
"근거 없으면 null" 원칙을 AI가 정확히 지킨 결과다. **정답 정의와 프롬프트의 불일치**지 AI 오류가 아니다.

> **수정안:** 프롬프트에 규칙 추가 — "레버리지/인버스 배율 언급이 없으면 `1.0`으로 반환하고 근거원문에 '해당 없음' 표기."

### 원인 ③ 복제방식 (오답 4건, 전부 null) — 프롬프트 문제

동일 구조. B·C는 실물복제지만 문서에 "실물복제"라는 단어가 없다(합성일 때만 스왑 조항이 명시됨).
같은 조건에서 어떤 런은 `"실물"`, 어떤 런은 `null`이 나와 재현성 저하의 주범이기도 하다.

> **수정안:** "스왑·장외파생 조항이 없으면 `실물`" 규칙을 넣을지, CLAUDE.md 원칙 3에 따라
> `검증필요` 플래그만 남길지 **사람 판단 필요**(11절).

## 5. 근거 실재성 검증

### 결과: 198/220 = **90.0%** (기준 90%) — **기준선 정확히 충족** ✅

regex 수정 전에는 193/215 = 89.8%로 0.2%p 차 미달이었다. 종목명 5건이 정답으로 편입되며 기준선에 올라섰다.

다만 **기준선에 정확히 걸쳐 있어 여유가 없다.** `총보수`를 빼면 189/193 = **97.9%**이므로,
남은 마진 부족은 사실상 `총보수` 단일 필드 문제다. 아래 수정을 v2에 반영하면 안정적으로 확보된다.

### 총보수 — 27/27 정답인데 근거는 9/27

원인이 **두 가지**로 갈린다. 실측으로 분리했다.

**(a) 표 행은 정확히 인용했으나 AI가 주석을 덧붙임 — 채점기 문제에 가까움**

```
"투자신탁 | 0.209 | 0.001 | 0.02 | 0.02 | 0.25 | 0.05 | 0.3 | - | 0.3
(표에서 발췌)"
```
검증: 표 행만 넣으면 **코퍼스에 그대로 존재(매칭 성공)**. `(표에서 발췌)` 한 줄 때문에 실패.
→ 프롬프트에서 주석 금지하면 해소.

**(b) AI가 표를 요약 재구성 — 구조적 한계**

```
"투자신탁 ... 총보수 0.5"
```
검증: `...`으로 분할해 조각별로 검사해도 `총보수 0.5`가 **코퍼스에 없다.**
PDF 표가 선형 텍스트로 펴지면서 헤더(`총보수`)와 값(`0.5`)이 수십 자 떨어져 있기 때문이다.

```
... 판매수수료 / 총보수 / 동종유형 총보수 / 총 보수ㆍ비용 / 1년 / 2년 ...
투자신탁 - 0.5 0.01 - 0.51 52 107 164 286 637
```

**표에서 온 값은 연속 substring 인용이 원리적으로 불가능한 구간이 있다.**
AI는 표를 올바로 읽었고(값 27/27 정답) 출처 표도 정확히 짚었다. 검증 방식이 이 케이스에 안 맞는 것.

> **수정안 (병행 권장):**
> 1. 프롬프트: "근거원문은 문서에서 **수정 없이 그대로** 복사. 생략(`...`)·재구성·주석 추가 금지.
>    표에서 인용할 때는 `----- [표 복원 p.N] -----` 블록의 **행 전체**를 그대로 복사."
>    → 코퍼스에 이미 파이프 표가 복원돼 있으므로(`build_corpus.py`) 실현 가능. (a) 해소.
> 2. 채점기: 표 유래 수치 필드는 **연속 substring 대신 "같은 표 행 안에 값이 존재하는가"**로 검증.
>    → (b) 해소.
>
> 참고로 `...` 분할 재시도만으로는 (b)가 안 풀린다. 실측 확인함.

## 7. 실패 방식 (기준: null > 확신 있는 오답)

| 유형 | 건수 |
|---|---|
| `null` 반환 (모른다고 답함) | **14** |
| 확신 있는 오답 (틀린 값을 자신 있게 반환) | **0** |

**기준 충족 (14 > 0).** regex 수정 전 5건으로 집계되던 것은 전부 종목명 표기 변형이었고,
채점 정규화가 고쳐지면서 정답으로 편입됐다. **틀린 값을 확신 있게 반환한 사례는 이제 하나도 없다.**

**사전지식 오염 0건.** "TIGER TDF2045는 보통 …" 같은 환각이 단 1건도 관측되지 않았다.
서비스 관점에서 잘못된 위험 판정을 내보낼 리스크는 현재 프롬프트에서 확인되지 않았다.

## 9. 부수 관측

- **JSON 파싱 실패 0/28.** Structured Outputs 스키마 강제가 안정적으로 동작.
- **페이지 번호 추출 성공.** `evidence_page`에 값이 채워짐(예: 기초지수 p.24, 비교지수 p.25).
  → 근거 패널 UI("P. 42") 성립 가능. **조항 번호("제2부 9-나")는 미수집** — 필요 시 스키마 확장.
- **표 복원 파이프라인이 유효하다.** `build_corpus.py`가 `----- [표 복원 p.N] -----` 블록으로
  수치 격자표를 복원해 두었고, 총보수 27/27 정답은 이 덕분이다. 비전 OCR 불필요 재확인.
- **비교지수(Tier1 `지수` 슬롯의 일부)도 27/27 추출.** Tier2 확장 시 재활용 가능.
- **파일럿의 실제 성과는 모델 검증이 아니라 정답지 검증이었다.**
  A 1종 파일럿에서 **ground_truth 오류 4건**(종목명/기초지수/비교지수/분배정책)을 발견해 수정했다.
  특히 A 분배정책은 명세서 원안 `무분배` → 실제 조항 확인 후 `연분배`로 정정. 파일럿 단계가 값을 했다.
- **`score_extraction.py`는 Python 3.10+ 필요** (`int | None` 표기).
  시스템 `python3`은 3.9.6이라 `TypeError`로 죽는다. **반드시 `.venv/bin/python`으로 실행할 것.**
  → README나 스크립트 상단에 명시 권장.
- 파일럿 1회(`A_C1_r1_1787362595`)가 본실행과 같은 `raw/`에 남아 있어 `score_extraction.py`가 28런으로 집계한다.
  본 보고서는 27런으로 분리 집계했다. **파일럿을 별도 디렉토리로 옮기는 것을 권장.**
