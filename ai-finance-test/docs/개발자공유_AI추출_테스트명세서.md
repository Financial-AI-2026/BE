# AI 추출 검증 테스트 명세서

> **목적**: 투자설명서에서 AI가 필요한 정보를 뽑아낼 수 있는지 검증 **범위**: 샘플 3종 대상 추출 테스트 (서비스 개발 착수 전 타당성 확인) **작성일**: 2026-08

---

## 0\. 이 테스트를 왜 하나요

우리 서비스는 **"ETF 투자설명서를 AI가 읽고, 사용자 상황에 맞는 위험을 알려주는 것"** 이 핵심입니다.

따라서 개발에 들어가기 전에 확인해야 할 단 하나의 질문이 있습니다.

> **투자설명서에서 필요한 항목이 실제로 추출되는가?**

이게 안 되면 나머지 기능(개인화 경고, 이름 함정 탐지)은 전부 성립하지 않습니다.

## 1\. 샘플 데이터 3종

전부 미래에셋자산운용(TIGER) 상품이며, 구조 유형이 서로 다르게 선정했습니다.

| \# | 종목명 | 종목코드 | 표준코드 | 구조 유형 |
| :---- | :---- | :---- | :---- | :---- |
| **A** | TIGER 미국S\&P500레버리지(합성 H) | 225040 | KR7225040005 | 레버리지 \+ 합성복제 \+ 환헤지 |
| **B** | TIGER 배당커버드콜액티브 | 472150 | KR7472150002 | 커버드콜 \+ 액티브 \+ 월분배 |
| **C** | TIGER TDF2045 적격 | 0025N0 | KR70025N0008 | 타겟데이트 \+ 자산배분 |

### 선정 이유

- **A**: 위험 요소가 3개(레버리지·합성·환헤지) 겹친 최악 케이스. 하나라도 놓치면 실패  
- **B**: 이름에 '커버드콜'이 있지만 그게 무슨 뜻인지는 이름만으로 알 수 없음  
- **C**: 이름만 봐서는 무엇에 투자하는지 전혀 알 수 없는 케이스

### 각 종목의 실제 구조 (정답지)

**A. TIGER 미국S\&P500레버리지(합성 H)**

- S\&P 500 지수의 **일일수익률 2배(X2)** 추종  
- '합성' \= 증권사가 제공하는 장외파생상품 TRS를 통해 투자 (실물 주식 미보유)  
- 환헤지 상품 → 원달러 환율 변동 영향 작음  
- 총보수 0.25% / 상장일 2015-07-29  
- 구성종목: TIGER 미국S\&P500선물(H), 미국S\&P500 TRS(미래에셋증권) 등

**B. TIGER 배당커버드콜액티브**

- 유가증권시장 상장규정 제113조에 따른 **액티브 ETF**  
- 비교지수: '코스피200 커버드콜 5% OTM'  
- 국내 주식 60% 이상 투자 \+ **콜옵션 매도**로 프리미엄 확보  
- 주가하락 위험을 부분적으로 방어하는 대신 상승 이익은 제한됨  
- 분배금: 매월 마지막 영업일 기준 지급 (월분배)

**C. TIGER TDF2045 적격**

- 기초지수: S\&P Korea Target Date 2045 Global Index (KRW) PR  
- **글로벌 주식 \+ 국내외 채권**에 혼합 투자  
- 목표시점(2045)에 가까워질수록 위험자산 비중이 낮아지는 구조

## 2\. 추출 대상 항목 및 기대값

### Tier 1 — 필수 (이게 안 나오면 서비스 불가)

| 필드명 | 타입 | A 기대값 | B 기대값 | C 기대값 |
| :---- | :---- | :---- | :---- | :---- |
| `종목명` | string | TIGER 미국S\&P500레버리지(합성 H) | TIGER 배당커버드콜액티브 | TIGER TDF2045 적격 |
| `기초지수` | string | S\&P 500 | 코스피200 커버드콜 5% OTM | S\&P Korea Target Date 2045 Global |
| `레버리지배율` | float | **2.0** | 1.0 | 1.0 |
| `복제방식` | enum | **합성** | 실물 | 실물 |
| `환헤지여부` | enum | **헤지** | 해당없음 | 미헤지 |
| `전략유형` | enum | 레버리지 | **커버드콜** | **타겟데이트** |
| `분배정책` | enum | 무분배 | **월분배** | 무분배 |
| `총보수` | float | 0.25 | (확인필요) | (확인필요) |

**enum 값 정의**

- `복제방식`: 실물 / 합성  
- `환헤지여부`: 헤지 / 미헤지 / 해당없음  
- `전략유형`: 지수추종 / 레버리지 / 인버스 / 커버드콜 / 타겟데이트 / 액티브 / 기타  
- `분배정책`: 무분배 / 월분배 / 분기분배 / 반기분배 / 연분배

### Tier 2 — 개인화 경고 생성에 필요

| 필드명 | 타입 | 설명 | 검증 포인트 |
| :---- | :---- | :---- | :---- |
| `일일리밸런싱여부` | bool | 레버리지가 일간 기준인지 | **A에서 반드시 true**. 이게 없으면 "장기보유 위험" 경고 생성 불가 |
| `거래상대방위험` | bool | 스왑(TRS) 상대방 존재 여부 | A에서 true \+ 상대방 증권사명 |
| `고난도금융투자상품여부` | bool | 투자설명서 제1부 2-바 항목 | 규제당국이 인정한 위험 신호 |
| `주요투자자산` | string\[\] | 실제 편입 자산 | C에서 "글로벌 주식", "국내외 채권" |
| `목표시점` | int | TDF 전용 | C에서 2045 |
| `액티브여부` | bool | 액티브 ETF 여부 | B에서 true |

### 공통 필수 필드: 근거 원문

**모든 추출 항목에 대해 근거가 된 원문 문장을 함께 반환해야 합니다.**

"근거원문": {

  "레버리지배율": "제2부 9-나 ... 기초지수의 일일 수익률의 2배 ...",

  "복제방식": "제2부 9-가 ... 장외파생상품(TRS) 계약을 통해 ..."

}

이유:

1. 사용자에게 "AI가 지어낸 말이 아님"을 보여주는 신뢰 장치  
2. **근거를 못 찾으면 추출 실패로 처리** → 잘못된 값을 자신 있게 내놓는 사고 방지  
3. 심사 시 원문 대조 검증 가능

## 4\. 합격 판정 기준

### 정량 기준

Tier 1 필드 8개 × 샘플 3종 \= 총 24개 검증 포인트

\[성공\]    22개 이상 정확 (91%)  → 서비스 개발 진행

\[조건부\]  18\~21개 정확          → 종목명 파싱 보정 로직 추가 후 재테스트

\[실패\]    17개 이하             → 전처리 재설계 필요

### 종목명 파싱 보정 로직

종목명 자체에 이미 상당한 정보가 들어 있습니다. AI 추출 결과와 종목명 파싱 결과를 **교차검증**하면 정확도가 올라갑니다.

| 종목명 패턴 | 강제 설정값 |
| :---- | :---- |
| `(합성)` 포함 | 복제방식 \= 합성 |
| `(H)` 포함 | 환헤지여부 \= 헤지 |
| `레버리지` 또는 `2X` 포함 | 전략유형 \= 레버리지 |
| `인버스` 포함 | 전략유형 \= 인버스 |
| `커버드콜` 포함 | 전략유형 \= 커버드콜 |
| `TDF` \+ 4자리 숫자 | 전략유형 \= 타겟데이트, 목표시점 \= 숫자 |
| `TR` 포함 | 분배정책 \= 무분배 |
| `액티브` 포함 | 액티브여부 \= true |

## 7\. 데이터 확보 방법

### 이번 테스트 (수동)

운용사 홈페이지에서 직접 다운로드합니다.

미래에셋 TIGER ETF 공식 사이트

https://investments.miraeasset.com/tigeretf/ko/main/index.do

→ 각 상품 상세페이지 → 투자설명서 PDF

### 향후 자동화 (검증 후 진행)

| 경로 | URL | 용도 |
| :---- | :---- | :---- |
| DART 펀드공시 | `https://dart.fss.or.kr/dsab005/main.do` | 투자설명서 원문 검색 |
| OpenDART API | `https://opendart.fss.or.kr/` | 자동 수집 (API 키 무료 발급) |
| KRX 정보데이터시스템 | `http://data.krx.co.kr/` | 전 종목 목록·종목코드 |
| 금융투자협회 공시 | `https://dis.kofia.or.kr/` | 보수·수익률 등 보조 데이터 |

### DART API 사용 시 확인 필요 사항

1. **문서 필터링**: 응답의 `report_nm`(보고서명) 필드로 필터링. 단 표기가 "투자설명서" / "\[정정\]투자설명서" / "간이투자설명서" 등으로 갈릴 수 있으므로 실제 값 확인 필요  
2. **공시 단위**: ETF는 종목별이 아니라 **운용사 단위**로 공시될 가능성이 있음. 종목명 검색이 아니라 `corp_code`(운용사 고유번호)로 조회 후 문서 내에서 해당 ETF를 찾아야 할 수 있음  
3. **파일 형식**: `document.xml` API로 받는 원본 ZIP 안이 XML인지 PDF인지 문서마다 다름. XML이면 파싱이 훨씬 쉬움

**단, 위 3가지 확인보다 AI 추출 테스트가 먼저입니다.** 추출이 안 되면 파이프라인이 있어도 소용없습니다.

## 8\. 작업 순서

1\. 샘플 3종 투자설명서 수동 다운로드 (운용사 홈페이지)

        ↓

2\. 목차 기준 섹션 분할 전처리 구현

        ↓

3\. Tier 1 필드 추출 프롬프트 작성 및 테스트

        ↓

4\. 판정 기준 대조 → 성공/조건부/실패 판단

        ↓

5-a. \[성공\]   Tier 2 확장 \+ DART 자동화 검토

5-b. \[조건부\] 종목명 파싱 보정 로직 추가 후 재테스트

5-c. \[실패\]   전처리 방식 재설계
