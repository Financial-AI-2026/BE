# 우리 프로젝트, 왜 이걸 만드나요?

> 금융 지식이 없어도 읽을 수 있게 쓴 문서입니다. 회의 전에 이것만 읽고 오시면 충분해요.

---

## 0\. 30초 요약

우리는 **"ETF라는 금융상품을 살 때, 뭘 사는지 모르고 사는 문제"** 를 해결하는 서비스를 만듭니다.

- 다른 금융상품은 살 때 **"설명서 읽으셨죠?" 확인 절차**가 법으로 강제됩니다.  
- 그런데 ETF는 **그 절차가 없습니다.** 아무것도 안 읽고 바로 살 수 있어요.  
- 그래서 위험한 상품을 위험한지 모르고 사는 일이 생깁니다.  
- 우리는 **AI가 그 어려운 설명서를 대신 읽고, 사용자에게 맞는 위험만 골라서 쉽게 알려주는** 서비스를 만듭니다.

---

## 1\. 먼저, ETF가 뭔가요?

### 아주 쉽게 말하면 "여러 회사 주식을 묶어놓은 세트 상품"입니다.

삼성전자 주식 하나만 사면, 삼성전자가 망하면 내 돈도 같이 망합니다. 그래서 "한국 대표 기업 200개를 조금씩 다 담은 세트"를 만들어서 파는 게 ETF예요. 하나만 사도 200개 회사에 나눠서 투자한 효과가 나는 거죠.

### 왜 인기가 많냐면

- 소액으로 분산투자가 됩니다 (1만원으로도 200개 회사에 투자)  
- 주식처럼 앱에서 바로 사고팔 수 있습니다 (클릭 두 번이면 끝)  
- 종류가 정말 많습니다. 미국 기술주 세트, 반도체 세트, 배당 많이 주는 회사 세트, 금값 따라가는 세트 등등

### 그런데 여기서 문제가 시작됩니다

ETF는 종류가 **수백 가지**인데, 겉보기엔 다 비슷하게 생겼습니다. 이름도 다 비슷하고, 앱에서 사는 방법도 똑같아요.

그런데 **속을 뜯어보면 완전히 다른 구조**를 가진 것들이 섞여 있습니다. 이걸 모르고 사면 문제가 생기는 거예요.

---

## 2\. "투자설명서"가 뭔가요?

### 금융상품의 사용설명서입니다.

전자제품 살 때 들어있는 설명서처럼, 금융상품에도 설명서가 있어요. "이 상품은 이렇게 굴러갑니다, 이런 경우에 손해볼 수 있습니다" 같은 내용이 들어있습니다.

### 문제는 이게 **수십 페이지짜리 법률 문서**라는 겁니다.

- 분량이 30\~100페이지  
- 문체가 딱딱한 법률 용어  
- PDF 파일로만 제공  
- 휴대폰으로 보면 글씨가 개미만 함

솔직히 말해서, **아무도 안 읽습니다.**

---

## 3\. 핵심 문제: ETF만 설명서 확인 절차가 없습니다

### 다른 상품들은 강제로 확인시킵니다

은행이나 증권사 앱에서 펀드나 ELS 같은 상품에 가입해보면, 중간에 이런 화면이 반드시 나옵니다.

> ☐ 투자설명서를 확인하였습니다 ☐ 위험을 이해하였습니다 \[다음\]

이걸 체크하지 않으면 **가입 자체가 진행이 안 됩니다.** 법으로 정해진 절차거든요.

### 그런데 ETF는 이 화면이 없습니다

ETF는 그냥 주식 사듯이 삽니다. 종목 검색 → 수량 입력 → 매수 버튼. 끝. **설명서 얘기가 단 한 번도 안 나옵니다.**

### 왜 이런 차이가 생겼나요?

법에서 정한 기준이 **"어디서 사느냐"** 이기 때문입니다.

|  | 어떻게 사나 | 설명서 확인 |
| :---- | :---- | :---- |
| 펀드, ELS | 회사에 신청서를 내고 가입 (= "청약") | **필수** |
| ETF, 주식 | 거래소에서 다른 사람과 사고팔기 (= "매매") | **없음** |

ETF는 처음 만들어질 때만 "청약" 절차를 거치고, 그 다음부터는 거래소에서 주식처럼 사람들끼리 사고파는 구조예요. 그래서 개인이 앱에서 살 때는 법적으로 "매매"라서 설명서 의무가 안 걸립니다.

**중요한 건, ETF도 사실 펀드와 똑같은 상품이라는 겁니다.** 법적 분류상으로도 같은 '집합투자증권'이에요. 그런데 사는 방식이 주식과 같다는 이유만으로 설명 절차가 통째로 빠진 겁니다.

---

## 4\. 그래서 무슨 일이 벌어지나요?

### 실제로 자주 벌어지는 사고 예시 3가지

**① 레버리지 ETF를 장기 보유**

레버리지 ETF는 "지수가 1% 오르면 2% 오르는" 상품입니다. 많은 사람이 "그럼 장기로 들고 있으면 2배로 벌겠네?" 라고 생각합니다.

**아닙니다.** 이 상품은 **하루 단위로만** 2배를 맞추도록 설계되어 있어요. 지수가 오르락내리락 반복하면, 몇 달 뒤엔 지수는 제자리인데 내 돈만 줄어있는 일이 생깁니다.

> 예시: 지수가 100 → 110 → 100 (제자리) 레버리지는 100 → 120 → 98.2 (손해)

이건 설명서에 분명히 적혀 있지만, 아무도 안 읽어서 모릅니다.

**② 커버드콜 ETF를 시세차익 목적으로 매수**

"배당을 월 1%씩 준대\!" 하고 사는 상품이 있습니다 (커버드콜). 그런데 이 상품은 **주가가 크게 오를 때 그 이익을 포기하는 대신** 배당을 만들어내는 구조예요.

즉 "가격이 올라서 팔아 이득 보려는" 사람에게는 안 맞는 상품인데, 높은 배당률 숫자만 보고 사는 경우가 많습니다.

**③ 환헤지가 안 된 해외 ETF**

미국 주식에 투자하는 ETF를 샀는데, 미국 주가는 올랐지만 **환율이 떨어져서** 결과적으로 손해를 보는 경우가 있습니다. "환헤지"라는 장치가 있는 상품과 없는 상품이 따로 있는데, 이름만 봐서는 구분이 어렵습니다. (보통 이름 끝에 (H)가 붙으면 환헤지 상품입니다)

---

## 5\. "운용사 홈페이지에 다 있잖아요?"

맞습니다. 있긴 있어요.

KODEX, TIGER 같은 운용사 홈페이지에 들어가면 투자설명서, 구성종목, 위험요소가 다 게시되어 있습니다.

**그런데 실제로 도달이 안 됩니다.**

1. 살 때 열어보라고 강제하지 않음 → 있는 줄도 모름  
2. 있어도 수십 페이지 PDF → 열어도 안 읽음  
3. 읽어도 무슨 말인지 모름 → 법률 용어

>   
> **정보가 없는 게 문제가 아니라, 정보가 사용자에게 번역되지 않는 게 문제입니다.** 이게 우리 프로젝트의 핵심 문장입니다.

---

## 6\. 해외는 어떻게 하고 있나요?

이 문제를 우리만 발견한 게 아닙니다. 나라마다 대응이 다릅니다.

| 지역 | 어떻게 하나 |
| :---- | :---- |
| **유럽 (가장 강함)** | ETF도 예외 없이 **3페이지짜리 요약 문서(KID)** 를 거래 전에 반드시 제공. 이 문서가 없으면 판매 자체가 불법. → 미국 유명 ETF들이 이 문서를 안 만들어서, 유럽 사람들은 아예 못 삽니다. |
| **미국** | 강제 확인은 없지만, 운용사가 **매일** 보유종목과 거래정보를 웹에 공개하도록 의무화. "안 봐도 살 수는 있지만, 보려면 항상 최신 정보가 있다" 전략. |
| **미국 (위험상품)** | 레버리지 같은 위험한 상품만 따로 골라서, 사기 전에 **퀴즈를 풀게 하는** 방안 논의 중. 일부 증권사는 이미 시행 중. |
| **한국** | 레버리지 상품에만 사전교육 1시간 의무. **일반 ETF는 아무 장치 없음.** |

**우리 서비스의 포지션**: 한국에는 유럽 같은 제도가 없습니다. 법이 강제하지 않는 그 빈칸을, **민간 서비스가 자발적으로 채우는 것**이 우리 아이디어입니다.

## 7\. 우리가 만들 것

### 한 줄로: **"추천하지 않고, 진단합니다"**

### 왜 추천을 안 하나요?

"이 ETF가 좋아요\!" 하고 추천하는 서비스는 이미 많습니다. 그런데 여기엔 함정이 있어요.

추천 서비스는 보통 상품을 팔아주고 수수료를 받습니다. 그러다 보면 **"사용자에게 맞는 상품"이 아니라 "수수료 많이 주는 상품"** 이 위로 올라오게 됩니다. 이걸 '알고리즘 편향성'이라고 하고, 금융당국이 실제로 문제 삼고 있는 부분입니다.

우리는 **애초에 추천 기능을 안 만듭니다.** 그러면 이 논란에서 구조적으로 자유로워집니다. 그리고 이번 공모전 주최가 금융보안원(소비자보호·보안 담당)이라, 이 방향이 훨씬 잘 맞습니다.

### 그럼 뭘 하나요?

\[1\] 사용자가 자기 상황을 입력

    → 얼마나 오래 투자할 건지 (단기 / 장기)

    → 왜 투자하는지 (시세차익 / 매달 받는 돈 / 장기 자산 불리기)

\[2\] 관심있는 ETF 종목을 검색해서 선택

\[3\] AI가 그 상품의 투자설명서를 읽고 구조를 파악

\[4\] "당신의 목적에서는 이게 위험합니다" 를 쉬운 말로 설명

### 핵심 아이디어: **위험은 사람마다 다릅니다**

같은 상품이라도 누가 사느냐에 따라 위험한 정도가 다릅니다.

| 상품 | 이 사람에겐 괜찮음 | 이 사람에겐 위험 |
| :---- | :---- | :---- |
| 레버리지 ETF | 하루이틀 단타 치는 사람 | **10년 묻어두려는 사람** |
| 커버드콜 ETF | 매달 배당 받고 싶은 사람 | **가격 올라서 팔려는 사람** |
| 환헤지 없는 해외 ETF | 환율 변동 감수 가능한 사람 | **안정적 배당 원하는 사람** |

기존 서비스는 "이 상품 위험등급 1등급입니다" 라고 모두에게 똑같이 말합니다. 우리는 **같은 상품에 대해 사람마다 다른 경고**를 보여줍니다.

## 8\. AI는 정확히 뭘 하나요?

이 부분이 공모전에서 제일 중요합니다. "AI 썼습니다"가 아니라 **"AI가 아니면 불가능한 걸 시켰습니다"** 를 보여줘야 해요.

### AI가 하는 일 (2가지)

**① 읽기** — 수십 페이지 PDF에서 핵심 구조 뽑아내기

> 이 상품은 레버리지 2배 / 커버드콜 방식 / 환헤지 안 됨 / 합성복제

사람이 하면 상품 하나당 30분 걸리고, 문서 형식도 운용사마다 다 다릅니다. 정해진 규칙으로 프로그램을 짜기 불가능한 영역이라 AI가 필요합니다.

**② 번역** — 딱딱한 내용을 사용자 상황에 맞는 말로 바꾸기

> "장기 보유를 계획하고 계신데, 이 상품은 하루 단위로 2배를 따라가도록 만들어졌어요. 시장이 오르락내리락하면 몇 달만 지나도 예상과 크게 달라질 수 있습니다."

### AI가 안 하는 일 (1가지)

**판단** — "장기 투자자 \+ 레버리지 \= 위험" 이라는 판단 자체는 AI가 하지 않습니다.

이건 미리 정해둔 규칙표로 처리합니다.

| 조건 | 경고 |
| :---- | :---- |
| 레버리지 상품 \+ 장기 투자 | 복리 효과로 수익률 어긋남 |
| 커버드콜 \+ 시세차익 목적 | 상승장에서 이익 제한됨 |
| 환헤지 없음 \+ 안정적 수입 목적 | 환율 때문에 받는 돈이 변동 |

**왜 규칙으로 하나요?** AI에게 판단까지 맡기면 같은 질문에 매번 다른 답이 나올 수 있고, "왜 위험하다고 했어요?"에 답을 못 합니다. 금융 분야에서는 이게 치명적이라, **판단은 규칙 / 읽기와 설명은 AI**로 나눕니다.

### 그리고 하나 더: 근거를 항상 같이 보여줍니다

AI가 "이 상품은 레버리지입니다"라고 하면, **투자설명서 몇 페이지 어느 문장에서 나온 건지 원문을 같이 띄웁니다.**

AI가 지어낸 말이 아니라는 걸 사용자가 직접 확인할 수 있어야 하니까요.

## 9\. 개인정보는 안 받습니다

우리 서비스는 다음을 **일절 수집하지 않습니다.**

- 이름, 연락처  
- 계좌번호, 잔고, 거래내역  
- 로그인, 회원가입도 없음

받는 건 딱 두 가지: **투자 기간**과 **투자 목적**. 그것도 선택 버튼으로만요.

금융보안원이 주최하는 대회인 만큼, "정보를 최소한만 받는 설계"라는 점이 큰 강점이 됩니다.

## 10\. 어디까지 만들고, 어디부터 안 만드나요?

### 이번에 만드는 것 (MVP)

- 국내 상장 ETF **한 종목씩** 진단  
- 미리 준비한 **샘플 4종 정도** (레버리지형 / 커버드콜형 / 환헤지 없는 형 / 평범한 형)  
- 위험 규칙 4\~5개  
- 투자기간 \+ 투자목적 2가지 입력

### 이번엔 안 만드는 것

- 여러 종목을 한 번에 보는 포트폴리오 분석  
- 해외 상장 ETF (SPY, QQQ 같은 것)  
- ETN, ELS, 펀드 등 다른 상품  
- 수익률 예측  
- 실제 주문 기능

**왜 이렇게 좁히나요?** 넓게 벌리면 어느 것도 제대로 안 됩니다. 심사에서 중요한 건 "많은 기능"이 아니라 **"하나가 확실히 작동하는가"** 입니다. 안 만드는 것들은 "향후 확장 계획"으로 문서에 적어두면 오히려 플러스가 됩니다.

## 11\. 아직 안 정해진 것 (회의에서 이야기할 것)

1. **서비스 이름** — 현재 '리스크 렌즈'는 임시안입니다  
2. **샘플 종목 4개 확정** — 어떤 ETF로 시연할지  
3. **투자설명서를 어디서 가져올지**  
   - 1순위 후보: **DART(금융감독원 전자공시)** — 공식 API가 있어서 자동 수집 가능  
   - 보조: 운용사 홈페이지, 금융투자협회 공시  
   - → 실제로 원하는 문서가 나오는지 확인 필요

## 12\. 모르는 용어 사전

| 용어 | 쉬운 뜻 |
| :---- | :---- |
| **ETF** | 여러 주식을 묶어놓은 세트 상품. 주식처럼 앱에서 바로 사고팔 수 있음 |
| **투자설명서** | 금융상품의 사용설명서. 보통 수십 페이지 PDF |
| **레버리지** | 지수가 1% 오르면 2% 오르게 만든 상품. 반대로 떨어질 때도 2배 |
| **인버스** | 지수가 떨어지면 오르는 상품 (반대로 움직임) |
| **커버드콜** | 큰 상승 이익을 포기하는 대신 매달 배당을 만들어내는 구조 |
| **환헤지** | 환율 변동의 영향을 막아주는 장치. 이름에 (H)가 붙으면 적용된 상품 |
| **합성복제** | 실제 주식을 사는 대신 다른 금융회사와 계약을 맺어 수익을 맞추는 방식. 그 회사가 문제 생기면 위험 |
| **분배금** | ETF가 투자자에게 나눠주는 돈. 주식의 배당금과 비슷 |
| **다크패턴** | 사용자가 불리한 선택을 하도록 유도하는 화면 설계. 2026년 4월부터 금융상품에 대한 가이드라인 시행 중 |
| **MVP** | 최소 기능 제품. 핵심 기능만 만들어서 작동을 증명하는 버전 |
